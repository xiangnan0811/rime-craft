# 辅助码配置

辅助码是万象拼音的核心特色功能。通过在拼音编码后追加形码信息，可以大幅减少重码，提高单字输入效率。

## 辅助码方案

万象支持多种辅助码系统：

- **墨奇码**：基于字形拆分的辅助码
- **鹤形**：小鹤双拼配套的形码
- **自然码**：自然码双拼配套的辅助码
- **虎码**、**五笔**、**仓颉**：基于传统形码的辅助码
- **简单鹤**：鹤形的简化版本
- **汉心码**：基于笔画的辅助码

## 引导方式

- **直接辅助码**：在四个编码末尾直接追加辅助码，如 `wjag`（万）
- **间接辅助码**：在双拼后加 `/` 分隔，如 `wj/ag`
- **反引号引导**：输入拼音后按 `` ` ``，再输入辅助码

## 辅助码提示

启用提示后，候选词旁会显示对应的辅助码编码，方便学习和记忆。可以配置提示的字数（默认仅单字显示辅助码提示）。
