# 标点符号映射

Rime 对标点符号有完整的处理机制，可以区分中文模式和英文模式下的标点输出，并支持一键多符的候选选择。

## 概念解释

Rime 内置了两套标点符号映射：

- **`full_shape`（全角）**：中文输入模式下的标点，如 `，`、`。`、`""` 等
- **`half_shape`（半角）**：英文输入模式下的标点，即键盘上的原始标点

默认情况下，中文模式输出全角标点，英文模式输出半角标点。你可以通过 `punctuator` 配置段自定义每个按键的映射行为。

## 配置项说明

`punctuator` 段在方案的 `.custom.yaml` 中配置：

```yaml
patch:
  punctuator:
    full_shape:
      "/": "、"          # 单值：直接输出，不弹出候选
      "\"":              # 多值：弹出候选菜单
        pair:
          - "\u201c"     # 左双引号 "
          - "\u201d"     # 右双引号 "
      "'":
        pair:
          - "\u2018"     # 左单引号 '
          - "\u2019"     # 右单引号 '
    half_shape:
      "/": "/"           # 英文模式下 / 还是 /
```

### 映射类型

| 类型 | 配置格式 | 行为 |
|------|---------|------|
| 单字符 | `"键": "字符"` | 直接输出，不弹候选 |
| 多候选 | `"键": ["选项1", "选项2"]` | 弹出候选列表 |
| 成对引号 | `"键": {pair: ["开", "闭"]}` | 自动交替输出左/右引号 |

### 成对引号（`pair`）

`pair` 类型是专为引号设计的特殊映射。第一次按下该键输出 `pair[0]`（开引号），第二次输出 `pair[1]`（闭引号），如此交替。不需要手动区分左右引号。

## 默认标点映射

Rime 默认（以朙月拼音为例）的中文标点：

| 键 | 中文输出 |
|----|---------|
| `,` | `，` |
| `.` | `。` |
| `?` | `？` |
| `!` | `！` |
| `;` | `；` |
| `:` | `：` |
| `(` | `（` |
| `)` | `）` |
| `[` | `【` |
| `]` | `】` |
| `\` | `、` |
| `"` | `"` / `"` （成对） |
| `'` | `'` / `'` （成对） |

## 常见自定义

**让 `/` 输出 `、`（顿号）而非斜杠：**

```yaml
patch:
  punctuator/full_shape:
    "/": "、"
```

**让 `/` 弹出候选（可选顿号或斜杠）：**

```yaml
patch:
  punctuator/full_shape:
    "/":
      - "/"
      - "、"
      - "÷"
```

**完全禁用全角标点（中文模式也输出半角）：**

方法一：修改标点配置，将所有全角符号改为半角。
方法二：通过开关控制（在 `switches` 中添加 `ascii_punct` 开关，见[开关与杂项](./switches)）。

**自定义省略号和破折号：**

```yaml
patch:
  punctuator/full_shape:
    "-":
      - "——"
      - "－"
      - "-"
    "^":
      - "……"
      - "^"
```

## 注意事项

- 修改 `punctuator` 配置后必须**重新部署**才能生效
- `full_shape` 和 `half_shape` 是独立的两张映射表，需要分别配置
- 如果按键既有标点映射，又在 `speller` 中定义了用途（如字母键），`speller` 规则优先——标点映射只对非拼音输入状态下的按键生效

在编辑器中可以直观地修改这些设置，点击每个符号查看当前映射并快速调整。
