# 特殊输入

万象拼音内置了多种特殊输入功能，通过特定的触发码可以快速输入日期、时间、进行数学计算等。

## 日期时间

| 触发码 | 功能 |
|--------|------|
| `/rq` | 输出当前日期 |
| `/sj` | 输出当前时间 |
| `/xq` | 输出当前星期 |
| `/nl` | 输出农历日期 |
| `/jq` | 输出当前节气 |
| `/jr` | 输出近期节日 |
| `/tt` | 输出 Unix 时间戳 |

## 工具

| 触发码 | 功能 |
|--------|------|
| `V` + 表达式 | 数学计算器，如 `V1+2*3` |
| `U` + 编码 | Unicode 字符输入，如 `U4e07` |

## 输入统计

| 触发码 | 功能 |
|--------|------|
| `/rtj` | 今日输入统计 |
| `/tj` | 累计输入统计 |
