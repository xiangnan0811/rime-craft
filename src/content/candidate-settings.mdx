# 候选词设置

候选词面板是输入法最核心的交互界面。合理设置候选词数量和选择方式，能显著降低选词次数，提升输入效率。

## 概念解释

当你输入一段拼音时，Rime 会显示一列候选词供你选择。这个设置控制：

- **每页显示多少个候选词**（`page_size`）
- **用什么键来快速选词**（`alternative_select_keys`）

这两个设置共同决定了你的选词效率。候选词太少，需要频繁翻页；候选词太多，需要频繁扫描；选词键设计得不顺手，则会拖慢节奏。

## 配置项说明

在 `default.custom.yaml`（影响所有方案）或 `<方案名>.custom.yaml`（只影响该方案）中配置：

```yaml
patch:
  menu/page_size: 7
  menu/alternative_select_keys: "ASDFGHJKL"
```

### `menu/page_size`

每页显示的候选词数量，取值范围 1–9。

| 值 | 适用场景 |
|----|---------|
| 3–4 | 竖排候选词，屏幕空间紧张 |
| 5 | 平衡选项，适合大多数用户 |
| 7–9 | 希望减少翻页，愿意扫描更多候选词 |

推荐值：**5 或 7**。

### `menu/alternative_select_keys`

快速选词的备选键序列。默认情况下，数字键 `1`–`9` 对应候选词第 1–9 项。如果设置了 `alternative_select_keys`，这些字母键也可以用来快速选词。

```yaml
# 使用数字键选词（默认行为，无需配置）
# 按 1 选第1个，按 2 选第2个，以此类推

# 使用字母键选词（需配置）
menu/alternative_select_keys: "ASDFGHJKL"
# 按 A 选第1个，S 选第2个，D 选第3个……
```

**字母键的优势**：手指不需要离开主键盘区移动到数字行，选词速度更快，特别适合双拼用户（双拼本身用到字母，数字键用于选词反而不顺手）。

**字母键的劣势**：需要适应一段时间，且输入英文缩写时可能误触发选词。

## 常见搭配

**全拼用户的典型配置：**

```yaml
patch:
  menu/page_size: 5
```

数字键选词、5 个候选词，简单直接，上手无负担。

**双拼用户推荐配置：**

```yaml
patch:
  menu/page_size: 7
  menu/alternative_select_keys: "ASDFGHJKL"
```

7 个候选词减少翻页，字母键选词让手指保持在主键盘区。

**极简配置（配合精准词库）：**

```yaml
patch:
  menu/page_size: 3
```

如果词库优化得足够好，前 3 个候选词能覆盖大部分需求，减少干扰。

## 翻页键

候选词翻页默认使用 `PageUp` / `PageDown`，也常见用方括号 `[` / `]` 翻页的配置：

```yaml
patch:
  key_binder/bindings:
    - { when: paging, accept: bracketleft, send: Page_Up }
    - { when: has_menu, accept: bracketright, send: Page_Down }
```

在编辑器中可以直观地修改这些设置。
