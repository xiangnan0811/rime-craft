# 开关与杂项

Rime 的「开关」（Switches）是一套状态切换机制，允许用户在输入过程中动态切换某些功能——比如简繁转换、Emoji 显示、全半角标点等。

## 概念解释

开关本质上是一组带有名字的**状态变量**，每个开关可以处于若干状态之一（通常是 0 或 1）。用户按 `Ctrl+~` 进入方案菜单后可以切换各开关状态，部分开关也绑定了快捷键。

每个开关的行为由方案文件中的 `switches` 段定义：

```yaml
switches:
  - name: ascii_mode        # 开关名称（引擎识别）
    reset: 0                # 部署后默认状态（0=关闭）
    states: [中文, 西文]    # 两种状态的显示标签
  - name: simplification
    reset: 0
    states: [漢字, 汉字]
```

`reset` 字段指定**每次部署后**（或切换到该方案时）开关的默认状态。`0` 表示第一个状态（通常是关闭），`1` 表示第二个状态（通常是开启）。

## 常用开关详解

### Emoji 开关

控制候选词中是否出现 Emoji 表情符号。需要方案支持（如雾凇拼音内置 Emoji 词库）。

```yaml
patch:
  switches:
    - name: emoji_suggestion
      reset: 1              # 默认开启 Emoji
      states: [💀 关闭, 😄 开启]
```

设置 `reset: 0` 可以默认关闭 Emoji，减少干扰；设置 `reset: 1` 则默认开启。

### 简繁转换开关

控制候选词是以简体还是繁体输出。此功能依赖 OpenCC 转换库，Rime 内置。

```yaml
patch:
  switches:
    - name: simplification
      reset: 0              # 0=输出繁体（原始），1=转换为简体
      states: [繁體, 简体]
```

> **注意**：大多数面向简体用户的现代方案（如雾凇拼音）词库本身就是简体，`simplification` 开关此时无实际效果。该开关主要用于繁体方案（如朙月拼音原版）转换为简体输出。

### 全角 / 半角字符开关

控制字母和数字是输出全角（如 `Ａ`、`１`）还是半角（`A`、`1`）。

```yaml
patch:
  switches:
    - name: full_shape
      reset: 0              # 默认半角
      states: [半角, 全角]
```

绝大多数用户应将此开关保持在半角（`reset: 0`），全角字符在现代排版中用途有限。

### 中英标点开关（`ascii_punct`）

控制中文输入模式下是否输出中文标点。

```yaml
patch:
  switches:
    - name: ascii_punct
      reset: 0              # 0=中文标点，1=英文标点
      states: [中文标点, 英文标点]
```

开启后（`reset: 1`），即便在中文输入模式下，逗号、句号等也输出半角形式（`,`、`.`），适合需要中英混排且不希望打出中文标点的用户。

## 开关的工作原理

Rime 中开关的切换通过 `key_binder` 中的按键绑定触发，或通过方案选单（`Ctrl+~`）手动切换。

以为 `simplification` 绑定 `Ctrl+Shift+F` 为例：

```yaml
patch:
  key_binder/bindings:
    - { when: always, accept: Control+Shift+F, toggle: simplification }
```

`toggle` 动作会在当前状态和下一个状态之间循环切换。

## 完整示例配置

以下是一个常见的开关配置，适用于大多数简体用户：

```yaml
# luna_pinyin_simp.custom.yaml 或 rime_ice.custom.yaml
patch:
  switches:
    - name: ascii_mode
      reset: 0
      states: [中文, 西文]
    - name: full_shape
      reset: 0
      states: [半角, 全角]
    - name: simplification
      reset: 1              # 简体方案保持简体输出
      states: [漢字, 汉字]
    - name: ascii_punct
      reset: 0
      states: [中文标点, 英文标点]
    - name: emoji_suggestion
      reset: 1
      states: [💀 无Emoji, 😄 有Emoji]
```

在编辑器中可以直观地修改这些设置，每个开关都有清晰的说明和默认值选项。
