# 输入方案管理

输入方案（Schema）是 Rime 的核心概念之一。一个方案定义了一套完整的输入规则：如何将按键序列转化为候选词、使用什么词典、支持哪些功能开关。Rime 允许你同时安装多个方案，按需切换。

## 概念解释

每个输入方案由一个 `.schema.yaml` 文件定义，文件名中包含方案的唯一 ID（`schema_id`）。例如：

- `luna_pinyin_simp.schema.yaml` → 方案 ID 为 `luna_pinyin_simp`（朙月拼音·简化字）
- `double_pinyin_flypy.schema.yaml` → 方案 ID 为 `double_pinyin_flypy`（小鹤双拼）

`default.custom.yaml` 中的 `schema_list` 字段控制哪些方案出现在切换菜单中。

## 配置项说明

在 `default.custom.yaml` 中配置方案列表：

```yaml
patch:
  schema_list:
    - schema: luna_pinyin_simp      # 朙月拼音·简化字（全拼）
    - schema: double_pinyin_flypy   # 小鹤双拼
    - schema: wubi86                # 五笔 86 版
```

**规则：**
- 列表中的方案按顺序显示在切换菜单（`Ctrl+~`）中
- 只有列在 `schema_list` 中的方案才会被加载，其他 `.schema.yaml` 文件不会生效
- 重新部署后，第一个方案成为默认选中的方案

## 主流输入方案介绍

### 雾凇拼音（`rime_ice`）

目前最受欢迎的全拼方案，特点是词库大、词频准确、支持自动纠错。需要单独安装。

```yaml
- schema: rime_ice  # 需先安装雾凇拼音方案文件
```

### 朙月拼音（`luna_pinyin_simp`）

Rime 内置的标准全拼方案（简体字版本），开箱即用，适合作为起点。

```yaml
- schema: luna_pinyin_simp
```

### 小鹤双拼（`double_pinyin_flypy`）

双拼方案之一，将每个音节压缩为两键，适合追求高速输入的用户。Rime 内置此方案。

```yaml
- schema: double_pinyin_flypy
```

### 万象拼音（`wanxiang`）

新一代全拼方案，支持辅助码功�，兼顾易用性与高效性。需单独安装。

### 五笔 86（`wubi86`）

经典形码输入法，字根固定、重码率低，适合专业用户。需配合对应词库使用。

## 常见搭配

**只用一种方案（不显示切换菜单）：**

```yaml
patch:
  schema_list:
    - schema: rime_ice
```

**全拼 + 双拼双修，方便切换：**

```yaml
patch:
  schema_list:
    - schema: rime_ice
    - schema: double_pinyin_flypy
```

**多方案用户：**

```yaml
patch:
  schema_list:
    - schema: rime_ice
    - schema: double_pinyin_flypy
    - schema: wubi86
    - schema: cangjie5
```

## 安装新方案

Rime 本身只内置少量方案。要使用雾凇拼音、万象拼音等第三方方案，需要将对应的 `.schema.yaml` 和 `.dict.yaml` 文件复制到用户配置目录，然后将方案 ID 加入 `schema_list`，重新部署即可。

推荐使用 [东风破（plum）](https://github.com/rime/plum) 包管理器批量安装方案：

```bash
bash rime-install rime-ice  # 安装雾凇拼音
```

在编辑器中可以直观地修改这些设置，无需手动管理文件。
