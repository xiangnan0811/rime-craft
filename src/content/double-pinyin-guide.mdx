# 双拼方案原理与选择指南

## 什么是双拼

双拼（Double Pinyin）是一种拼音输入的优化方案。全拼输入一个汉字音节通常需要 2 到 6 次按键，而双拼通过重新映射声母和韵母，让**每个音节固定只需按 2 个键**——第一键输入声母，第二键输入韵母（含介音）。这样大幅减少了击键次数，理论上输入速度可比全拼提升 30%–50%。

举例：全拼输入"想"需要按 `x-i-a-n-g`（5 键），双拼中只需按 `x-b`（2 键，取决于方案）。

## 双拼的核心原理

汉语拼音的音节结构是：**声母 + 韵母**（韵母包括介音 + 元音 + 韵尾）。双拼把所有常见韵母压缩映射到键盘上的单个按键，使得：

- 零声母音节（如"啊 a"、"鹅 e"）用特殊规则处理，通常以元音本身或固定键开头
- 声调一般不参与双拼编码，靠候选词排序处理

## 主流双拼方案对比

### 小鹤双拼

由"何海峰"设计，是目前使用人数最多的双拼方案。其设计特点：

- 韵母分布尽量均衡，左右手交替使用，减少同手连击
- `ln` 同键（声母 l/n 共用一键），对有 l/n 不分口音的用户友好
- 学习资源丰富，社区活跃，Rime 官方生态支持完善

### 自然码

历史最悠久的双拼方案之一，1990 年代随同名输入法流行：

- 键位设计直觉性强，如 `ui` → `v`、`ue` → `t`
- 支持辅助码（形码）配合使用，可大幅降低重码率
- 在老一代用户中口碑好，但新用户学习资料相对较少

### 微软双拼

随 Windows 内置输入法推广，键位分配保守规整：

- 与全拼记忆迁移成本低，声母位置和全拼一致
- 韵母分布不如小鹤均衡，部分韵母需同手连击
- 适合偶尔用双拼、不想花大量时间练习的用户

### 搜狗双拼

随搜狗拼音输入法流行，布局介于自然码和微软双拼之间：

- 在搜狗输入法用户中拥有一定基础
- 切换到 Rime 后可直接沿用，无需重新记忆键位

## 在 Rime 中切换双拼

在 `default.custom.yaml` 中的 `schema_list` 加入对应方案即可（详见[输入方案管理](./schema-manager)）：

```yaml
patch:
  schema_list:
    - schema: double_pinyin_flypy   # 小鹤双拼
    - schema: double_pinyin         # 自然码
    - schema: double_pinyin_mspy    # 微软双拼
    - schema: double_pinyin_sogou   # 搜狗双拼
```

部署后在状态栏切换，或在 `squirrel.custom.yaml` / `weasel.custom.yaml` 中设置默认方案。

## 学习建议

1. **先选定一个方案**：建议初学者选小鹤双拼，资料最丰富
2. **背熟键位表**：打印一张韵母键位对照表，贴在显示器旁
3. **每天练习 15 分钟**：推荐使用 [双拼练习网站](https://api.ihint.me/shuang/) 或 Typist 类工具
4. **容忍过渡期**：头两周速度会下降，坚持 3–4 周后速度会超越全拼
5. **不要切换回全拼**：一旦退回全拼，肌肉记忆会被覆盖，进度大幅倒退

双拼是提升拼音输入效率最直接的方式，掌握后很难再回到全拼。
