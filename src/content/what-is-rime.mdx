# Rime 是什么

Rime，全称**中州韵输入法引擎**（Rime Input Method Engine），是一个开源、跨平台的输入法框架。它本身不是一款具体的输入法，而是一个底层引擎——在不同操作系统上，它以不同的名称和外观出现，但共享同一套配置逻辑和输入方案。

## Rime 的核心特点

**开源自由**：Rime 以 BSD 许可证开源，代码完全透明。任何人都可以查看、修改和分发它。没有商业公司控制它的走向，功能由社区共同推动。

**高度可定制**：从候选词数量、翻页按键，到输入方案的拼写规则、词库构成，几乎所有行为都可以通过 YAML 配置文件精确控制。这种灵活性是商业输入法无法比拟的。

**全平台支持**：Rime 引擎运行在主流桌面和移动平台上，各平台发行版如下：

| 平台 | 发行版名称 | 安装来源 |
|------|-----------|---------|
| macOS | 鼠须管（Squirrel） | brew / rime.im |
| Windows | 小狼毫（Weasel） | rime.im |
| Linux（IBus） | ibus-rime | 包管理器 |
| Linux（Fcitx5） | fcitx5-rime | 包管理器 |
| Android | 同文输入法（Trime） | F-Droid / GitHub |
| iOS | 仓输入法（Hamster） | App Store |

**隐私保护**：Rime 完全本地运行。你输入的每一个字符都在本机处理，不会上传到任何云端服务器。对于注重隐私的用户，这是一个决定性优势。

**多方案支持**：一套 Rime 安装可以同时运行全拼、双拼、五笔、仓颉、粤语拼音等多种方案。切换方案只需按一个快捷键，无需重新安装。

## Rime 与商业输入法的区别

商业输入法（如搜狗、讯飞、百度输入法）的优势在于：开箱即用、词库庞大、云端同步方便、有专业团队持续优化。

Rime 的优势在于：

- **没有广告和推广词**：商业输入法经常在候选词中插入广告，Rime 没有这类问题。
- **配置可迁移**：你的所有配置都是纯文本文件，可以用 Git 管理，跨设备同步，永久保存。
- **方案可扩展**：社区有大量开源方案，如雾凇拼音（带词频优化的大词库全拼）、小鹤双拼、万象拼音等，可以自由选用。
- **行为可预期**：Rime 不会在某次更新后悄悄改变你的输入习惯。

## 什么时候适合选择 Rime

Rime 适合以下用户：

- 对输入法有精细定制需求，希望"一切在掌控之中"
- 使用双拼或其他非主流输入方案
- 注重输入数据隐私，不希望输入内容上传
- 需要在多个平台使用同一套配置（配置文件可以直接复制）
- 想要学习和探索输入法工作原理的技术用户

如果你只是需要一个"够用就行"的输入法，商业方案或许更省心。但如果你愿意花一点时间配置，Rime 能给你带来更贴合自己习惯的输入体验——而且这套体验是你完全拥有的。
