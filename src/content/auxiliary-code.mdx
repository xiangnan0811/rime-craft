# 辅助码系统详解

## 什么是辅助码

拼音输入法最大的痛点是**重码**——同音字太多，候选词列表冗长，需要频繁翻页选字。辅助码（Auxiliary Code）是一种在拼音之后追加字形信息的机制，通过额外的 1–2 个字形编码，将候选词快速缩减到 1–3 个，几乎实现"盲打选字"。

辅助码并不替代拼音，而是在拼音编码之后补充字形维度的信息，从而形成"音形结合"的输入体验。

## 两种辅助码类型

### 直接辅助码

在拼音编码后**直接连打**字形码，不需要额外触发键。以自然码辅助码为例：

- 输入"码"字：`ma` + `dc`（取"码"字的字形码 dc）→ 直接上屏

优点是效率最高，缺点是与纯拼音模式的候选词会混合显示，不熟悉时容易混乱。

### 引导辅助码

在拼音之后先按一个**引导键**（常见为 `` ` ``、`Tab` 或 `;`），再输入字形码。以虎码辅助码为例：

- 输入"码"字：`ma` → 按 `` ` `` → 输入 `dc` → 候选列表大幅缩减

引导键将两种模式明确分隔，切换感更清晰，适合刚接触辅助码的用户。

## 常见辅助码系统

| 名称 | 字形基础 | 特点 |
|------|----------|------|
| 自然码辅助码 | 部首 + 笔画 | 历史悠久，与自然码双拼配套使用 |
| 小鹤音形 | 字根（类五笔） | 小鹤双拼配套，重码率极低 |
| 虎码 | 字根 | 独立的音形方案，社区维护活跃 |
| 仓颉辅助码 | 仓颉字根 | 适合已会仓颉的用户 |

## 在 Rime 中配置辅助码

以引导辅助码为例，在方案的 `*.schema.yaml` 中配置：

```yaml
# 在 translator 节配置辅助码
translator:
  dictionary: your_dict
  prism: your_schema
  # 辅助码过滤器
  filters:
    - lua_filter@aux_code_filter

# 引导键定义
recognizer:
  patterns:
    aux_code: "^[a-z]+`[a-z]*$"   # 反引号为引导键
```

对于直接辅助码，通常通过自定义词典格式在词条末尾附加字形码列，并配合 `filter` 脚本过滤候选。

具体配置因方案不同差异较大，建议直接使用社区维护的完整方案包（如"雾凇拼音"内置了多种辅助码选项）。

## 实际使用示例

以小鹤音形为例，输入"学"字：

1. 纯拼音输入：`xue` → 候选列表可能有 10+ 候选
2. 加辅助码：`xue` + 引导键 + `ip`（取"学"的字根码）→ 候选缩减到 1–2 个

熟练之后，常用字可以做到**直接一选**，无需翻页，这是辅助码最大的价值所在。

## 学习路径建议

1. 先用纯拼音熟悉 Rime 基本操作
2. 选择一个辅助码方案（推荐小鹤音形或虎码）
3. 只对高频重码字练习辅助码，不必强求每字都用
4. 随使用时间延长，自然覆盖更多字形记忆

辅助码的学习曲线比双拼更陡，但配合使用后，输入效率可以再上一个台阶。
