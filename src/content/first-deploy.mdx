# 第一次部署

安装 Rime 后，你需要执行一次「部署」操作才能正常使用输入法。每次修改配置文件后，也需要重新部署。

## 什么是「部署」

Rime 的配置是用 YAML 文本文件编写的，人类可读但计算机处理效率较低。「部署」（Deploy）是 Rime 将这些文本配置文件**编译成高效的二进制数据**的过程。

具体来说，部署过程包括：

1. 读取用户目录下的所有配置文件（`*.yaml`、`*.custom.yaml`）
2. 将 `.custom.yaml` 的补丁合并到对应的基础配置中
3. 编译词典文件（`.dict.yaml`）为二进制格式
4. 生成可供引擎直接使用的运行时数据，存放在 `build/` 子目录中

**每次修改配置后必须重新部署**，否则改动不会生效。这是初学者最容易忽略的步骤。

:::warning
在修改配置文件之前，建议先备份整个用户配置目录。错误的 YAML 语法可能导致部署失败，备份可以让你随时恢复到正常状态。
:::

## 如何触发部署

### macOS（鼠须管）

点击菜单栏右上角的输入法图标，在弹出菜单中选择**「重新部署」**。

部署过程中图标会出现短暂的旋转动画，完成后恢复正常。

### Windows（小狼毫）

在系统托盘中找到小狼毫图标（通常在右下角），**右键点击**，选择**「重新部署」**。

### Linux（ibus-rime）

```bash
# 方法一：命令行触发（推荐）
ibus restart

# 方法二：如果安装了 rime-deploy 工具
rime_deployer --build ~/.config/ibus/rime
```

### Linux（fcitx5-rime）

```bash
# 重启 fcitx5 即可触发重新部署
fcitx5 -r
```

或者在 fcitx5 配置工具中找到「重新部署」按钮。

### Android（同文输入法）

打开同文输入法的设置界面，找到**「重新部署」**按钮，点击执行。

### iOS（仓输入法）

打开仓输入法的设置页面，在「Rime」选项中点击**「重新部署」**。

## 第一次部署后的默认状态

首次部署成功后，Rime 会加载内置的默认方案。不同平台略有差异，但通常会包含：

- **朙月拼音**（全拼）：最基础的拼音输入方案
- **仓颉五代**（部分平台）
- **注音符号**（部分平台）

按 `Ctrl+~`（反引号配合 Control）可以呼出方案选单，查看当前已启用的方案。

## 常见问题

**问：部署后输入法没有响应，什么都输不出来？**

答：检查配置文件中是否有 YAML 语法错误。Rime 对 YAML 格式要求严格，多一个空格或少一个冒号都会导致部署失败。打开日志文件（见下方）可以看到具体报错。

**问：日志文件在哪里？**

- macOS：`$TMPDIR/rime.squirrel.ERROR` 或 `~/Library/Logs/Rime/`
- Windows：`%TEMP%\rime.weasel.ERROR`
- Linux：`~/.config/ibus/rime/rime.ibus.ERROR` 或类似路径

**问：部署速度很慢？**

答：首次部署需要编译词典，如果启用了大词库（如雾凇拼音），可能需要 10–30 秒。后续部署如果词库未变化，速度会明显更快。

**问：部署后之前的配置全部丢失了？**

答：Rime 不会删除你的配置文件。请检查用户配置目录中的文件是否还在。如果是使用 `.custom.yaml` 补丁的配置，请确认补丁语法正确（需要有 `patch:` 根键）。
