Input Schema Management

Configure which input schemas are available and their switching order

Input Schema is one of Rime's core concepts. A schema defines a complete set of input rules: how to convert key sequences to candidates, which dictionaries to use...

Configuration

Configure the schema list in default.custom.yaml:

default.custom.yaml 📋 Copy
patch:
  schema_list:
    - schema: luna_pinyin_simp
    - schema: double_pinyin_flypy
💡 Tip
Only schemas listed in schema_list will be loaded after deploy.

Layout Summary

Desktop (≥1280px) Left sidebar (220px) + Content (flex) + Right TOC (180px)
Tablet (768–1279px) Left sidebar (180px) + Content (flex). TOC → floating button
Mobile (<768px) Full-width content. Sidebar → hamburger overlay. Search → icon
Content features Breadcrumbs, prev/next navigation, "Go to Editor" button, dark code blocks
