Design Tokens Summary

Accent Blue-500 (light) / Blue-400 (dark) — consistent with existing app theme
Font System font stack for prose, SF Mono/Monaco/monospace for code
Code blocks Always dark (slate-800/900), both modes. Syntax highlighting via shiki or rehype-pretty-code
Callouts 4 types: Tip (blue), Warning (yellow), Note (green), Caution (red). Using remark-directive in MDX
Toggle Respects existing Tailwind dark: class + user preference via localStorage
